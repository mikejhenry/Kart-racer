# Kart Racer

An arcade kart racer made with **Godot 4.5** (GDScript), with a small **Cloudflare** server for online play. It runs on desktop, in the browser, and on phones.

**Play in your browser:** https://mikejhenry.github.io/Kart-racer/

## Modes

- **Grand Prix:** 3 laps against 5 computer karts on Easy, Normal or Hard. The difficulty sets the speed of every kart and how well the computer karts drive.
- **Time Trial:** 3 laps solo, with no items. You can race your best run's **ghost**, the **world-record ghost** downloaded from the leaderboard, or no ghost. Each finished run goes onto that track's leaderboard.
- **Multiplayer:**
  - **Quick match** puts you in an open public lobby, which starts by itself 20 seconds after a second player joins.
  - **Private lobbies** use a 5-letter code. The host picks the track and difficulty, and can **fill empty spots with computer karts** (optional).
  - If your connection drops, the game rejoins the same race automatically. If the page reloads, use **Rejoin lobby** on the start screen.

## Features

- **Drifting** with mini-turbos: blue sparks give a short boost, orange a longer one.
- **Items** come from item boxes, with a roulette. Karts further back get better odds.
  - **Nitro:** a speed boost
  - **Missile:** homes in on the kart ahead
  - **Triple Missile:** three shots
  - **Oil Slick:** dropped behind you
  - **Shield:** blocks one hit, lasts 8 seconds
  - **Storm:** lightning strikes the race leader
- **Garage:** three kart styles (Classic, Speedster, Buggy) in ten colors. Other players see your choice online.
- **Sound and music:** original sound effects and two music loops, generated by `tools/make_audio.py`. Music and effects volumes are in Settings.
- **Minimap**, race timer, lap times, position, wrong-way warning and a pause menu.
- **Phones:** touch buttons, optional tilt steering, and vibration on hits, boosts and landings.
- **Computer karts** follow a racing line, drift through bends for mini-turbos, and use items tactically on Normal and Hard.

## Leaderboard checks

A time only counts if it comes with its recorded run, which is checked against the track's checkpoints. The server rejects runs that:
- have the wrong amount of data for their time
- don't start at the line
- move faster than any kart can
- skip checkpoints on any lap
- beat the track's minimum possible time

Submissions are rate-limited, and names are filtered for offensive words. The record holder's run is what you race in **World record** ghost mode.

## Setting up online play (one time)

The `Deploy` workflow deploys the server and the game together on every push to `main`. Without the two Cloudflare secrets below, the game still deploys, but with online play turned off.

1. Create a free account at [dash.cloudflare.com](https://dash.cloudflare.com). Open **Workers & Pages** once so Cloudflare sets up your `workers.dev` subdomain.
2. **Account ID:** go to **Workers & Pages** and copy the *Account ID* shown on the right.
3. **API token:** go to **My Profile → API Tokens → Create Token**, choose the **Edit Cloudflare Workers** template, then **Create**, and copy the token.
4. In this repo, go to **Settings → Secrets and variables → Actions → New repository secret** and add `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN`.
5. Go to **Actions → Deploy → Run workflow**. The server URL is written into the game automatically.

Everything runs on Cloudflare's free plan.

## Running locally

1. Install [Godot 4.5](https://godotengine.org/download). Use the standard build, not .NET.
2. In Godot, choose **Import**, pick `project.godot`, and press **F5**.
3. Optional, for online play: in `server/`, run `npm install wrangler` and then `npx wrangler dev`. Start the game with `KART_SERVER=http://127.0.0.1:8787`.

### Changing tracks or sounds

- Tracks are defined as data in `scripts/tracks.gd`. After changing one, regenerate the server's checkpoints:
  `godot --headless --path . --script res://tools/export_tracks.gd`
- Sounds and music are synthesized by `python3 tools/make_audio.py`, which needs numpy, scipy and ffmpeg.

### Server API

| Request | What it does |
|---|---|
| `GET /leaderboard?track=ID` | Top 10 for a track, best time per name |
| `POST /leaderboard` `{track, name, time, frames}` | Submit a run, which is checked, and get back your rank |
| `GET /ghost?track=ID` | The record holder's run |
| `POST /lobby` | Create a private lobby |
| `POST /quickmatch` | Code of an open public lobby, or a new one |
| `GET /lobby/CODE` | Whether a lobby exists, its phase and player count |
| `GET /lobby/CODE/ws?name=…&color=…&style=…` | WebSocket: lobby, settings, start, kart states, items, finishes, drop and rejoin |
